# Final-web Backend REST API Service

This directory contains the decoupled Laravel REST API service for the Collaborative Intelligent Note Management Web Application.

- **Framework:** Laravel Framework (PHP 8.3+)
- **Role:** Headless REST API service serving the decoupled React Single Page Application (`/frontend`)
- **Health Endpoint:** `GET /api/health`

## Governance & Operating Rules

All development on this backend is strictly governed by the root repository policy:

- Root Agent Rules: [`../AGENTS.md`](../AGENTS.md)
- Root Requirements: [`../docs/MASTER_REQUIREMENTS.md`](../docs/MASTER_REQUIREMENTS.md)
- Architecture Decisions: [`../docs/ARCHITECTURE_DECISIONS.md`](../docs/ARCHITECTURE_DECISIONS.md)
